# CLAUDE.md

Claude Code loads this file automatically. **It is a pointer, not the
instructions.**

> **Read `AGENTS.md` in this same folder now, and follow it.**

That file holds the identity and instructions for this folder. `AGENTS.md` is
the vendor-neutral filename that any coding agent can be pointed at, and this
system is built to outlast any particular model or product. The instructions
live there; this file only forwards to them.

**Do not put instructions here.** Two files of instructions is two sources of
truth, and they will drift — at which point the answer you get depends on which
tool you happened to open the folder with. If something needs saying, say it in
`AGENTS.md`.

Other vendors' entry files (`GEMINI.md`, `.github/copilot-instructions.md`, and
whatever comes next) can be added the same way: a short pointer, never a copy.
